## 1. 천간합충(天干合沖) 규칙

### 천간합(天干合) — 5가지
甲己合(토화) / 乙庚合(금화) / 丙辛合(수화) / 丁壬合(목화) / 戊癸合(화화)
- 합이 되면 오행이 변화됨 (합화 오행 우선 적용)
- 주변 글자가 충·극하면 합화 불성립 (合而不化)

### 천간충(天干沖) — 4가지
甲庚충 / 乙辛충 / 丙壬충 / 丁癸충
- 충은 그 기운을 흩어지게 함 (沖散)
- 연주·월주·일주·시주 위치별 영향도 다름

## 2. 지지형충파해(地支刑沖破害) 규칙

### 지지충(地支沖) — 6가지
子午충 / 丑未충 / 寅申충 / 卯酉충 / 辰戌충 / 巳亥충

### 지지형(地支刑) — 3종
- 무례지형(無禮之刑): 子卯形
- 지세지형(持勢之刑): 寅巳申 삼형
- 무은지형(無恩之刑): 丑戌未 삼형
- 자형(自刑): 辰辰 / 午午 / 酉酉 / 亥亥

### 지지해(地支害) — 6가지
子未해 / 丑午해 / 寅巳해 / 卯辰해 / 申亥해 / 酉戌해

### 지지합(地支合)
- 육합(六合): 子丑 / 寅亥 / 卯戌 / 辰酉 / 巳申 / 午未
- 삼합(三合): 寅午戌(화국) / 申子辰(수국) / 巳酉丑(금국) / 亥卯未(목국)
- 방합(方合): 寅卯辰(목) / 巳午未(화) / 申酉戌(금) / 亥子丑(수)

## 3. 용신(用神)/기신(忌神) 판단 로직

### 억부용신법(抑扶用神法) — 중화론 기반
1. 일간(日干)의 강약 판단:
   - 월령(月令) 득령/실령 확인 (가장 중요)
   - 생조(生助) 글자 수 vs. 극설(剋洩) 글자 수 비교
   
2. 일간이 강(身强)할 때:
   - 용신: 관살(官殺, 극아자) / 재성(財星, 아생자) / 식상(食傷, 아극자)
   - 기신: 비겁(比劫, 방조자) / 인성(印星, 생아자)
   
3. 일간이 약(身弱)할 때:
   - 용신: 인성(印星, 생아자) / 비겁(比劫, 방조자)
   - 기신: 관살(官殺) / 재성(財星) / 식상(食傷)

### 조후용신법(調候用神法)
- 월령 계절 기반 한난조습(寒暖燥濕) 균형 조정
- 겨울(亥子丑月) 사주 → 火 조후 필수
- 여름(巳午未月) 사주 → 水·金 조후 필요

### 병약용신법(病藥用神法)
- 사주의 병(病, 과다·결핍 오행) → 약(藥, 보완 오행)
- 예: 木 과다 → 金(극목) 또는 火(설목) 용신

## 4. 대운(大運)/세운(歲運) 계산 — 절기 기반

### 대운수(大運數) 계산
- 양남음녀(陽男陰女): 출생일 이후 → 다음 절기까지 일수 ÷ 3 = 대운수
- 음남양녀(陰男陽女): 출생일 이전 ← 직전 절기까지 일수 ÷ 3 = 대운수
- 1일 = 4개월 (통상), 3일 = 1년

### 대운 천간지지 산출
- 월주(月柱)를 기준으로 순행/역행
- 양남음녀: 월주 다음 간지 순서로 10년씩 진행
- 음남양녀: 월주 이전 간지 역순으로 10년씩 진행

### 세운(歲運) 해석 원칙
1. 세운 천간·지지가 일주와 충·합·형 여부 확인
2. 용신 세운: 길운 (吉年)
3. 기신 세운: 흉운 (凶年)
4. 충일주(沖日柱) 세운: 변동·이직·이사 등 큰 변화 암시

## 5. 십성(十星) 해석 규칙

일간(我) 대비 각 글자의 관계:
- 比肩: 같은 오행, 같은 음양 (동료·경쟁)
- 劫財: 같은 오행, 다른 음양 (빼앗김·파트너)
- 食神: 내가 생하는 오행, 같은 음양 (재능·표현)
- 傷官: 내가 생하는 오행, 다른 음양 (창의·반항)
- 偏財: 내가 극하는 오행, 같은 음양 (사업재·부친)
- 正財: 내가 극하는 오행, 다른 음양 (정당재·배우자)
- 偏官(七殺): 나를 극하는 오행, 같은 음양 (권위·압박)
- 正官: 나를 극하는 오행, 다른 음양 (명예·직업)
- 偏印(梟神): 나를 생하는 오행, 같은 음양 (편학·고독)
- 正印: 나를 생하는 오행, 다른 음양 (학문·모친)
